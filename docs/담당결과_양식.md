# 다차량 실험 담당 결과

담당자 / 담당 알고리즘(탐욕법·SA·ALNS) / 실행 날짜 / 사용한 PC와 Python 버전

## 구현과 실행

`solvers_multi.py`에서 맡은 함수와 직접 확인한 내용을 적는다. 실행 명령, 반복 횟수, 시드, 가중치(`--wait-weight`, `--late-second-cost`, `--late-stop-cost`), 근무시간 상한을 기록한다. 기본값을 바꿨다면 바꾼 이유도 적는다.

## 같은 조건에서 측정한 결과

`python summarize.py`가 만든 `results/SUMMARY.md`의 비교표에서 자기 알고리즘 행을 옮겨 적는다. 값은 `시드 평균 / 중앙값`이다.

## 배정을 바꾼 효과

| 비교 | 원래 채점 비용 변화 | 전부 추정 채점 비용 변화 | 전부 추정 이동시간 변화 | 옮겨진 배송지 수 | 추정 구간 수 |
|---|---:|---:|---:|---:|---:|

원래 채점과 전부 추정 채점의 방향이 다르면 그대로 적는다.

## 실제 데이터에서 관찰한 동작

실행 하나를 골라 시드와 시나리오를 적고 예시를 든다. 탐욕법은 한 배송지의 삽입 후보와 비용, SA는 차량 간 이동 또는 교환 한 번의 전후 비용과 수용 여부, ALNS는 제거·복구 방법과 옮겨진 배송지를 보인다. `results/알고리즘/moves.csv`에서 어느 차량 사이로 많이 옮겨졌는지도 적는다.

## 해석과 확인

어느 지표가 얼마나 변했는가? 시드에 따른 변동, 반복 한도를 늘렸을 때의 변화, 이 표본의 한계는 무엇인가? 검산 명령(`python check_multi.py --results results`)의 결과와 커밋한 결과 폴더를 적는다. 저장소에 있던 결과와 `git diff`로 비교해 `runtime_seconds`와 `settings.json`의 PC 정보 말고 달라진 값이 있으면 적는다.
