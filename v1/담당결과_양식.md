# 배송 방문 순서 실험 담당 결과

담당자 / 담당 방법 / 실행 날짜 / 사용한 PC와 Python 버전

## 구현과 실행

담당 함수와 직접 작업한 내용, 입력·출력, 실행 명령을 기록한다. 탐색 방법은 초기 경로, 종료 조건, 시드와 탐색 시간도 적는다.

## 같은 조건에서 측정한 결과

| 방법 | 경로 수 | 시드 수 | 평균 이동시간(분) | 평균 지연 배송지(곳) | 평균 물품 지연 합(분) | 평균 계산시간(초) |
|---|---:|---:|---:|---:|---:|---:|
| 탐욕법 | | | | | | |
| 담당 탐색 방법(SA·ALNS 담당만 기재) | | | | | | |

## 실제 경로에서 관찰한 동작

경로 ID, 해당 배송지 수, 비교한 순서, 비용 전후를 쓴다. 탐욕법은 삽입 후보, SA는 변경과 수용 여부, ALNS는 제거·복구 방법을 하나씩 예시로 든다. 설명용 한 단계와 전체 제한시간 실험에서 얻은 측정값을 구분한다.

## 해석과 확인

어떤 조건에서 어느 지표가 얼마나 변했는가? 시드에 따른 변동이나 선택한 표본의 한계는 무엇인가? 검산 명령과 결과, 첨부한 출력 폴더를 적는다.
