# 다차량 실험 요약

이 파일은 `python summarize.py` 가 결과 폴더에서 자동으로 만든다. 직접 고치지 않는다.

- A: 기록된 배정 + 기록된 순서
- B: 기록된 배정 + 알고리즘 순서 (배정 고정)
- C: 알고리즘 배정 + 알고리즘 순서. 탐욕법이 처음부터 배정하고 SA·ALNS 는 그 해에서 출발한다.
- C2: C 와 같지만 SA·ALNS 가 B 의 탐욕 해(기록된 배정)에서 출발한다.

## 설정

- 비용 = 이동 + 1 × 대기 + 5 × 지각 초(물품별) + 600 × 지각 배송지 수
- 근무시간 상한(차량별 출발~마지막 배송 완료): 29,639.2초 = 8.23시간 (longest recorded route)
- 탐욕법: 결과 있음
- SA: 반복 8,000,000회, 시드 11, 29, 47, 61, 83
- ALNS: 반복 80,000회, 시드 11, 29, 47, 61, 83

표의 값은 `시드 평균 / 중앙값`이다. 실행이 하나뿐인 행(A, 탐욕법)은 값 하나만 적는다.
